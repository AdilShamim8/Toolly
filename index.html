The questions beginners actually ask — answered plainly.

Do I need to know how to code?

No. Every guide and example starts with ordinary tasks and plain language. If you can write an email, you can use the tools here. Programming only matters if you later choose the developer categories.

Which AI chatbot should I start with?

Start with one of the big three — ChatGPT, Claude or Gemini. All three have free tiers, and each has a different strength: ChatGPT for versatility and images, Claude for careful writing and long documents, Gemini for Google-integrated research. The choosing lesson walks you through it in five minutes.

Are these tools really free?

Every card carries a pricing label: Free, Freemium (free tier + paid upgrade), Paid, or Open Source. The directory has a one-click pricing filter, so you can see only what costs nothing if that’s your budget.

How do I know the listings are current?

The directory is hand-curated and correctable: entries are checked for working links, real descriptions and accurate pricing, and anyone can submit a correction or a new tool from the directory page. Trending and Newly Added lists update as the collection grows.

What if I try a tool and it doesn’t work for me?

That’s normal — and useful. Note what felt off (too slow, wrong tone, too expensive), open the tool’s Similar Tools row in the directory, and try a neighbour. Finding your fit usually takes two or three attempts.
